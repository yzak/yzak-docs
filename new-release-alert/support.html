新えん本 - サポート

アプリについて

「新えん本」は、エンジニア向け技術書の新刊情報を一覧・タグ別に確認できるアプリです。ユーザーは興味のあるタグを購読し、毎週のローカル通知で新刊を確認できます。

主な機能：

  • 技術書新刊一覧の表示
  • タグ絞り込み
  • 書籍詳細画面での情報確認
  • 購読タグ設定
  • ローカル通知設定
  • Amazon商品ページへの外部ブラウザ遷移

よくある質問

Q1. 書籍データはどこから取得していますか？

GitHub Pages 上で公開している書籍JSONを取得して表示しています。データの生成元は Amazon の公式APIを前提としたバックエンドです。

Q2. 通知はいつ判定されますか？

通知判定はアプリ起動時または手動更新時に行います。通知時刻にネットワークへアクセスして判定するのではなく、取得済みデータをもとにローカル通知を予約します。

Q3. Amazonへのリンクはアプリ内ブラウザですか？

いいえ。Amazonの商品ページは外部ブラウザで開きます。アプリ内ではまず書籍詳細を確認できます。

Q4. 書籍が表示されないことがあります。

データ更新タイミングや対象タグ、公開JSONの内容によっては、新刊がない期間があります。手動更新を試しても表示が変わらない場合は、配信データ側に新しい対象書籍がまだ含まれていない可能性があります。

Q5. どの情報が端末に保存されますか？

購読タグ、通知設定、前回取得済み書籍ID、書籍JSONキャッシュなどを端末内に保存します。ログイン情報や課金情報は扱いません。
