プライバシーポリシー

最終更新日: 2026年03月24日

本アプリ「新えん本」（以下、「本アプリ」といいます）は、ユーザーの皆様のプライバシーを尊重し、個人情報の保護に努めます。本プライバシーポリシーは、本アプリがどのような情報を扱い、どのように利用するかについて説明するものです。

1. 取得・保存する情報

本アプリは、主に以下の情報を取り扱います。

  • アプリ設定情報: 購読タグ、通知の有効/無効、通知曜日、通知時刻、前回取得済みの書籍ID、取得済みJSONキャッシュを端末内にローカル保存します。
  • コンテンツ取得情報: GitHub Pages 上で公開される書籍JSONを取得し、新刊一覧を表示します。
  • 通知関連情報: ローカル通知を予約するために必要な設定を端末内に保存します。

2. 利用目的

取得・保存した情報は、以下の目的で利用します。

  • 技術書新刊一覧の表示
  • 購読タグに応じた表示・通知対象の絞り込み
  • ローカル通知の予約
  • 前回取得との差分判定
  • アプリの安定した動作のためのキャッシュ管理

3. 第三者サービスとの連携

本アプリは以下の外部サービスまたは外部サイトを利用します。

  • GitHub Pages: 書籍情報JSONの配信元として利用します。
  • Amazon: 書籍詳細の確認や購入導線として、外部ブラウザで商品ページを開きます。リンクにはアソシエイトタグが付与される場合があります。

本アプリ自体は、ユーザーの個人情報を独自サーバーへ送信・保存しません。

4. データの保存場所

本アプリで保存される設定情報やキャッシュ情報は、お使いの端末内にローカル保存されます。アプリを削除した場合、これらのデータは削除されます。

5. 通知について

本アプリの通知はサーバープッシュではなくローカル通知です。通知判定はアプリ起動時または明示的な更新時に行い、その結果をもとに次回通知を予約します。

6. 子どものプライバシー

本アプリは13歳未満の子どもを主な対象としていません。13歳未満の子どもから意図的に個人情報を収集することはありません。

7. セキュリティ

本アプリは端末内保存を中心とした構成を採用していますが、インターネット通信や端末利用に伴うすべてのリスクを完全に排除できるものではありません。

8. 本ポリシーの変更

本ポリシーは必要に応じて変更することがあります。重要な変更がある場合は、本ページの更新をもって通知します。
